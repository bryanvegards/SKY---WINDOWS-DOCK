# Sky

A lightweight, Apple-style dock for Windows 11.

Sky replaces the Windows taskbar with a clean Liquid Glass dock: macOS-style magnification,
live window previews, and small widgets for weather, music, battery, time and notifications.

## Download

**[⬇ Download the latest version](https://github.com/bryanvegards/SKY---WINDOWS-DOCK/releases/latest)**

On that page, under **Assets**, click **SkySetup-x.x.x.exe**.

## Install

1. Open the downloaded **SkySetup** file.
2. If Windows shows *"Windows protected your PC"*, click **More info** › **Run anyway**.
   (This appears because Sky is a small independent app without a paid certificate. It's safe.)
3. Follow the installer. No admin rights needed, and nothing else to install.
4. Tick **Start Sky when I sign in** if you want it every time you turn on your PC.

The Windows taskbar hides while Sky runs and comes back whenever Sky closes.

## Using Sky

| Do this | What happens |
|---|---|
| Hover the dock | Icons magnify, names appear |
| Rest on an open app | See a live preview of each of its windows |
| Click an app | Open it; click again to minimize |
| Right-click the dock | Settings: size, icon style, pinned apps, auto-hide |
| Click the date | Opens your calendar |
| Click the bell | Your recent notifications |
| Wi-Fi / Bluetooth / ⚙ | Windows' own quick settings |

To pin an app, right-click its icon in the dock › **Keep in Dock**, or pin it to the taskbar
from the Start menu as usual.

## Updates

Sky updates itself. New versions download in the background and install while you're away from
the computer. To check right away: right-click the dock › **General** › **Check for updates**.

## Uninstall

**Settings › Apps › Installed apps › Sky › Uninstall.** Your normal taskbar comes back.

## Requirements

Windows 11 (or Windows 10 version 2004 or later), 64-bit.
